## Featured project

### Aptoria

Aptoria is my self-hosted API QA, security review and regression monitoring platform.

It is built for practical QA work around API projects, including project-based test organization, scan results, findings, snapshots, release readiness checks, regression monitoring, report exports, and operational QA documentation.

The goal of Aptoria is to provide a lightweight, practical and transparent tool for API quality work, especially for smaller teams, freelancers, portfolio demonstrations, and self-hosted QA workflows.

Key areas covered by Aptoria:

* API QA project management
* Endpoint and scan result review
* Security review support
* Regression monitoring
* Release readiness checks
* Findings and snapshot handling
* Markdown, HTML and PDF reports
* Export credits and attribution metadata
* QA evidence and release documentation
* Windows/XAMPP friendly Laravel deployment
* GitHub Actions compatible QA gate
